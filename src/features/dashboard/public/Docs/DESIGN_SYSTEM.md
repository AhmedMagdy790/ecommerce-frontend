# نظام التصميم (Design System)

## 1. لوحة الألوان (Color Palette)
- **Primary:** `bg-blue-600` (للأزرار الأساسية والإجراءات).
- **Secondary:** `bg-gray-800` (للعناوين والنصوص).
- **Accent:** `bg-orange-500` (للخصومات وتنبيهات السلة).
- **Success:** `bg-green-600` (لعمليات الشراء الناجحة).

## 2. الطباعة (Typography)
- **Font Family:** 'Inter', sans-serif.
- **H1:** `text-4xl font-bold` (عناوين الصفحات).
- **Body:** `text-base text-gray-700` (النصوص العادية).

## 3. المكونات الأساسية (Atomic Components)
- **Buttons:** 
  - `BtnPrimary`: خلفية زرقاء، حواف دائرية (rounded-lg)، Padding مناسب.
  - `BtnOutline`: إطار أزرق، بدون خلفية.
- **Cards:** 
  - `ProductCard`: إطار بظلال خفيفة (`shadow-sm`)، صورة في الأعلى، السعر بالأسفل.

## 4. المسافات والقياسات (Spacing & Layout)
- **Container:** `max-w-7xl mx-auto px-4`.
- **Gap:** `gap-4` للشبكات (Grid) و `space-y-6` للقوائم العمودية.
